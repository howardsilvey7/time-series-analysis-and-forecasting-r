# ACF and PACF Outputs

This directory contains generated autocorrelation and partial-autocorrelation analysis artifacts.

Typical generated files include:

- theoretical ACF values;
- theoretical ACF plot;
- simulated-process ACF;
- simulation summary;
- original-series ACF/PACF;
- first-difference ACF/PACF;
- first-and-seasonal-difference ACF/PACF.

Analytical files in this directory are generated programmatically.
